# altair must stay below 5.4. From 5.4 on it declares classes as
#   class X(TypedDict, closed=True)
# which only works where typing_extensions supplies TypedDict itself. Streamlit
# Cloud builds on Python 3.14, where that falls through to the standard
# library's TypedDict, which rejects the argument:
#   _TypedDictMeta.__new__() got an unexpected keyword argument 'closed'
# 5.3.0 has no such declaration anywhere. The projector only uses long-stable
# altair APIs (Chart/X/Y/Color/Tooltip/Scale/Axis/StrokeDash/Row/Column), so
# nothing is lost by staying there.
